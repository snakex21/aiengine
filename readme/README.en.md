# AIEngine — 2.5D Game Engine

**AI-built. AI-driven. Open source forever.**

AIEngine is a Doom-style 2.5D game engine written from scratch in Go.
Models, textures, sounds, and game logic are designed to be generated by LLMs.
The renderer uses raycasting with CPU pixel-buffer — no GPU shader hell,
guaranteed to work on any OpenGL 3.3+ card.

## Quick Start

```bash
git clone https://github.com/snakex21/aiengine.git
cd aiengine
go mod tidy
go build -o aiengine.exe .
./aiengine.exe
```

**Requirements:** Go 1.26+, OpenGL 3.3+, Windows 10/11 64-bit.

## Architecture

```
Go Core (engine, renderer, parser)
├── GLFW          Native window
├── OpenGL 3.3    Raycasting renderer
├── gopher-lua    Lua VM (mission logic, NPC AI)
├── goja          JS VM  (UI, HUD, menus)
└── Custom Parser .aie / .css / config
```

| Language | Role |
|----------|------|
| **Go** | Engine, renderer, physics, parser |
| **Lua** | Mission logic, enemy AI, events |
| **JS** | UI, HUD, menus, effects |
| **CSS** | Colors, textures, screen effects |

Everything is compiled into a **single .exe** — zero external runtimes.

## File Formats

### .aie — Entities, Maps, Weapons, Sounds
Indentation-based format with 3 complexity levels:

```aie
# Level 1 — simple
HUMANOID grunt
HP 50
HEAD small skin

# Level 2 — blocks
HP_PARTS
  HEAD 25
  TORSO 60

# Level 3 — full control
ANIM idle
  FRAME 0
    HEAD ROT 0 5 0
  FRAME 30
    HEAD ROT 0 -5 0
END
```

Supported entity types: `HUMANOID`, `ALIEN`, `MUTANT`, `ROBOT`, `UNDEAD`, `QUADRUPED`, `MULTI_LEG`, `FLYING`, `AQUATIC`, `AMORPHOUS`, `SERPENTINE`, `GIANT`, `VEHICLE`, `PROP`, `WEAPON`, `MAP`.

### .css — Styling & Effects

```css
.gangster {
    color: #4A4A4A;
    texture: cloth;
}

screen {
    vignette: 0.3;
    film-grain: 0.1;
}

player:low-hp {
    vignette: 0.8;
    red-tint: 0.3;
    pulse: yes;
}
```

Supports: inheritance (`extends`), pseudo-classes (`:pain`, `:dead`), procedural textures (`noise(perlin, scale=2.0, seed=42)`), screen-space effects.

### config.aie — Keybindings & Settings

```
WINDOW_WIDTH 1280
WINDOW_HEIGHT 720

BIND move_forward W
BIND shoot MOUSE_LEFT
BIND fullscreen F11
BIND pause ESCAPE
```

## Scripting

### Lua — Mission Logic

```lua
function onEnemyDead(id, enemyType)
    local kills = getVar("kills") + 1
    setVar("kills", kills)
    if kills >= 10 then
        unlockDoor("door_boss")
        showMessage("Boss door opened!")
    end
end
registerEvent("onEnemyDead", onEnemyDead)
```

**45+ API functions:** `spawnEnemy()`, `getPlayerHP()`, `unlockDoor()`, `playSound()`, `showMessage()`, `getVar()`, `registerEvent()`, `winGame()`...

### JavaScript — UI & HUD

```js
Engine.on("onPlayerDamage", function(amount) {
    UI.setFilter("red_flash", 0.8);
    UI.setHP(Engine.getPlayerHP(), 100);
});

Engine.on("onPause", function(paused) {
    if (paused) UI.showPauseMenu();
    else UI.hideMenu();
});
```

**`Engine.*`** (25+ methods) + **`UI.*`** (25+ methods): HUD, menus, screen filters, minimap, dialog.

## Building

```bash
# Requirements: Go 1.26+, CGO enabled (for GLFW)

git clone https://github.com/snakex21/aiengine.git
cd aiengine
go mod tidy
go build -o aiengine.exe .

# Run tests
go test ./...       # 74 tests
go vet ./...        # static analysis
```

### Development Dependencies
- `github.com/go-gl/glfw` — window management
- `github.com/go-gl/gl` — OpenGL bindings
- `github.com/yuin/gopher-lua` — Lua VM
- `github.com/dop251/goja` — JavaScript VM

All dependencies are fetched automatically by `go mod tidy`.

## Configuration

Edit `demo/config.aie`:

```aie
# Window
WINDOW_WIDTH 1280
WINDOW_HEIGHT 720

# Keybindings
BIND move_forward W
BIND move_backward S
BIND move_left A
BIND move_right D
BIND shoot MOUSE_LEFT
BIND fullscreen F11
BIND pause ESCAPE
```

All key names from GLFW are supported: `W`, `SPACE`, `ESCAPE`, `F11`, `MOUSE_LEFT`, `LEFT_SHIFT`, etc.
